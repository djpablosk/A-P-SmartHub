## 📖 About

**A&P SmartHub** is a central gateway that connects hardware and software for intelligent home management. It provides real-time monitoring of environmental data such as gas levels, temperature, and humidity — and lets you control lights, view Spotify playback, and manage all connected IoT devices from a single, clean interface.

Built on object-oriented C# with .NET async pipelines and ESP32 microcontrollers for hardware data collection.

---

## ✨ Features

- 📊 **Main Dashboard** — Real-time telemetry overview: temperature, gas, humidity, errors, and connected devices
- 🤖 **AI Chat Assistant** — Built-in AI layer for natural-language home control
- 💡 **Light Control** — Interactive RGB LED color and brightness management
- 🌡️ **Climate Control** — Dedicated widgets for ventilation and temperature settings
- 📡 **Device Management** — Full hardware overview and management of all connected IoT nodes
- 🎵 **Spotify Connector** — Integrated Spotify streaming and now-playing display
- 🔔 **Smart Alerts** — Automated critical email notifications (e.g. gas detection alerts)
- 🔐 **User Authentication** — Secure login, registration, and password reset via email
- ⚙️ **Settings** — Account and application configuration center

## 🚀 Getting Started

### Prerequisites

- [.NET Framework](https://dotnet.microsoft.com/download/dotnet-framework)
- [MySQL](https://dev.mysql.com/downloads/) database server
- ESP32 microcontroller with firmware flashed (C++)
- Visual Studio (recommended)

### Installation

```bash
git clone https://github.com/djpablosk/A-P-SmartHub.git
```

1. Open `A&P SmartHub.slnx` in Visual Studio.
2. Configure your database connection string in the app settings.
3. Flash the ESP32 firmware for your hardware node.
4. Build and run the application.
